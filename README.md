# Billpal skills

Free skills for Claude and ChatGPT. Each skill runs on its own. A Billpal account makes some of them easier, because the assistant can read invoices and contacts the user already has. Without an account, the user supplies the same details in the chat.

- [Invoice generator](invoice-generator/): writes a normal invoice in a Billpal template, your own file, or a plain default.
- [SEPA file generator](sepa-file-generator/): builds one SEPA credit-transfer file (pain.001.001.09) for upload to business online banking. Needs an assistant that can run Node.

To use a skill, copy its folder into your assistant's skills.

Billpal: https://billpal.io
